# FE-组件任务
**时间戳**: 2026-04-18 21:10:27

## 本轮目标
修复登录不跳转根因：AppModal 滚动测量逻辑重入导致栈溢出。

## 工作项
1. 改造 AppModal 的滚动测量逻辑为“聚合查询 + 单次 exec”。
2. 禁止在 exec 回调中再次对同一 query 调用 exec。
3. 若必须分步测量：使用不同 query 实例 + measuring 互斥标志 + 防抖。
4. 校准可见性切换时序，避免动画阶段频繁测量。
5. 保持业务行为不变（仅修复组件层机制）。

## 验收标准
- 登录页点击“模拟扫码成功”后可稳定跳转。
- 无 `RangeError: Maximum call stack size exceeded` 前端报错。
- 弹窗在“可滚动/不可滚动”场景提示逻辑正确。
- 前端 `lint`、`type-check`、`build:h5` 全通过。

## 输出
- 提交修复 PR（聚焦组件，不混入无关改动）。
- 在 `docs/feedback/FA.md` 覆盖写入本轮总结（带时间戳）。
