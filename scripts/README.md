# 脚本目录说明（开发与测试）

本目录仅用于开发、测试、业务诊断脚本，不承担生产运维职责。

## 目录约定

- `backend/`：后端诊断、测试、数据处理脚本
- 根目录脚本：本地开发辅助脚本（如端口清理、浏览器调试）
 
为避免入口分散，业务无关的一次性脚本统一放在 `scripts/**`；业务模块内部不再新建 `src/scripts` 之类的目录。

## 与 ops 的边界

- `scripts/**`：开发侧工具，目标是定位业务或代码问题
- `ops/**`：生产侧工具，目标是保障环境可用性与发布稳定性
- 禁止在 `scripts/**` 增加发布、回滚、生产备份、网络配置下发能力

## 使用规范

- 默认在本地或测试环境执行
- 涉及写操作脚本需先确认目标环境和数据库
- 高风险脚本执行前先备份并做二次确认

## 变更规则

- 脚本目录变更必须经过 Trae 助手评审与执行，不允许手工直接改动
- 若需新增脚本，先在变更说明中写明用途、风险级别、执行环境
